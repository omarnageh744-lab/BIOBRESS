## 1. Dataset Overview

## 2. Data Quality Inspection

The initial inspection identified:

- No completely duplicated rows.
- One repeated Opportunity ID (Opp = 788), representing two different observations.
- Missing values in HHaction and Missedbutglove.
- Inconsistent Shift category: "After noon" instead of "Afternoon".
- Imbalanced target distribution.

## 3. Data Cleaning

The Shift category was standardized:

- Before: After noon
- After: Afternoon

The cleaned dataset was saved as:

data/hand_hygiene_data_cleaned.csv

No records were deleted.

The repeated Opp value was retained because the two records represent different observations.

## 4. Missing Values Analysis

Missing values:

| Column | Missing Count | Percentage |
|---|---:|---:|
| HHaction | 715 | 77.97% |
| Missedbutglove | 202 | 22.03% |

All other columns contain zero missing values.

The missing-value investigation showed a complete association between the missingness patterns of these two columns and the target Complied.

These columns were excluded from model predictors because of data leakage risk.

Missing values were not artificially filled.

## 6. Feature Encoding

OneHotEncoder was tested on the four categorical features.

Results:
- Original Features: 4

LabelEncoder was tested on the target:

- No = 0

The encoding experiment was saved in:

scripts/encode_features.py

This experiment was performed on the full dataset for validation only. It is not the final training or evaluation procedure.

## 7. Preprocessing Pipeline

A preprocessing pipeline was configured using:

- ColumnTransformer
- OneHotEncoder
- Pipeline

The configuration is saved in:

scripts/build_preprocessing.py

The preprocessing pipeline was validated using an 80/20
stratified train-test split.

The pipeline was fitted on training data only and used
to transform testing data.

Both datasets produced 17 encoded features.

For model evaluation, preprocessing must be fitted separately inside each training fold to prevent data leakage.

## 10. Limitations

The dataset contains 917 observations and represents a limited data source.

Model results should not be interpreted as causal evidence or used for staff ranking, surveillance, or disciplinary decisions.

Opportunity ID (Opp) Limitation:

The meaning and uniqueness of Opp could not be independently confirmed.

One repeated Opp ID (788) was found in two different observations.

All records were retained.
Opp was excluded from model features.

The independence of observations should be considered
when designing model validation and interpreting results.
